How I actually make all this.

I’m basically the director. I pick what we’re making, set the rules and decide when something is actually done. A team of AI models does a lot of the heavy lifting inside those rules, and a few tools I built keep everyone on the same page.

01 · Process

Me plus an AI crew

Every project runs kind of like a small studio. Each model has its own job, they pass work to each other in writing, and nothing ships until it’s tested and I’ve looked at it myself.

  • →Clear roles. ChatGPT owns art, assets and publishing. Claude owns gameplay systems, code, effects and balance.
  • →Shared memory. Every project keeps a handoff file and a conversation log, so whichever model picks it up next already knows what was decided.
  • →Research, don’t guess. Characters should fight the way they do in their shows, so moves and effects get looked up in the source material instead of made up.
  • →Prove it. Combat changes have to pass automated checks and simulated fights first. One Bazaar hero update had 52 checks and 90 test fights behind it.
  • →Real players. Friends playtest every build, and their run stats go to a small server I run so I can use them for balancing.

02 · Tools

Things I built to build things

Whenever something kept wasting my time, I made a tool for it.

Max-AI

My own assistant that runs locally through Ollama with Gemma, with free cloud models as backup. It learns from my corrections and thumbs downs, and it follows step by step playbooks for jobs like finding card art. It also remembers long chats and gives me a receipt for every file it saves.

Conversation Recall

A searchable archive of every conversation I’ve had with ChatGPT, Codex, Claude and Max-AI. Any of them can look up what was said and decided, so nothing gets forgotten or repeated.

Asset Scout

A research routine that searches the web for game assets like models, icons, sprites, sounds and music, and logs every find with its link, license and how well it fits the game.
